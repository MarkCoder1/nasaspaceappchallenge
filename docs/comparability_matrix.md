# TerraMatch comparability matrix

Comparability is assessed for later scientific analysis, not for visual similarity. A variable is only `DIRECT` when the measured physical quantity, units, spatial semantics, and observation conditions are sufficiently aligned. This Phase 3 input set contains only a Mars terrain raster, so no cross-body variable is promoted to `DIRECT`.

| Variable            | Earth data                                                 | Moon data                                                                 | Mars data                                                 | Comparable?        | Conditions and limitations                                                                                                                                                                                                                      |
| ------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Elevation           | NASADEM, 30 m HGT tiles; not acquired                      | LOLA product required; product scale and datum not yet fixed              | Jezero CTX DTM, 20 m, Mars 2000 Equirectangular; acquired | CONDITIONAL        | Elevation is a physical quantity in metres, but body radii, vertical datums, planetary geodetic conventions, product resolution, and coverage differ. Compare body-specific terrain metrics only after explicit datum and resolution decisions. |
| Slope               | Derivable from NASADEM                                     | Derivable from selected LOLA grid                                         | Derivable from CTX DTM in Phase 4                         | CONDITIONAL        | Derivation depends on the native body geometry, grid spacing, vertical datum, and treatment of missing cells. No slope output is created in Phase 3.                                                                                            |
| Terrain roughness   | Derivable from NASADEM                                     | Derivable from selected LOLA grid                                         | Derivable from CTX DTM in Phase 4                         | CONDITIONAL        | Roughness is scale-dependent and algorithm-dependent. Equal window sizes in pixels do not represent equal physical areas across products.                                                                                                       |
| Surface temperature | MOD11A2 is 1 km, 8-day land-surface temperature/emissivity | Diviner radiance/temperature products are product- and geometry-dependent | THEMIS products are product-dependent                     | NOT COMPARABLE     | Sensor physics, viewing geometry, emissivity, illumination, temporal aggregation, and product calibration differ. A shared Kelvin unit would not make these measurements equivalent.                                                            |
| Thermal inertia     | No selected Earth product                                  | No selected lunar product                                                 | TES archive is product-dependent and not selected         | NOT COMPARABLE     | Thermal inertia requires a validated product definition and unit, not a temperature proxy.                                                                                                                                                      |
| Reflectance/albedo  | No selected product                                        | No selected product                                                       | THEMIS or other product-dependent                         | NOT COMPARABLE     | Illumination, photometric correction, wavelength, atmospheric effects, and surface composition differ.                                                                                                                                          |
| Geological unit     | Earth geology not selected                                 | USGS Unified Geologic Map is categorical                                  | Mars geology not selected                                 | NOT COMPARABLE     | Categorical maps are interpretive context, not a continuous measurement; classification schemes are not shared across bodies.                                                                                                                   |
| Data quality mask   | NASADEM product flags, not acquired                        | LOLA product flags, product-dependent                                     | CTX internal mask and nodata metadata                     | DIRECT for QA only | QA masks can be compared as metadata conventions only after each source's flag semantics are documented. They are not environmental similarity variables.                                                                                       |

## Processing consequence

Phase 3 creates only a Mars elevation variable in metres, preserving native geometry and masking. No cross-body normalized variable is created. The future similarity methodology must use body-aware terrain preparation and should not compare raw pixel elevations or pixel indices directly.
