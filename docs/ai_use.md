# AI use disclosure

TerraMatch source code and documentation were developed with AI-assisted programming support under human direction and review.

AI assistance was used for:

- Code scaffolding and refactoring suggestions.
- Test fixture and API schema drafting.
- Documentation organization and wording.

Scientific dataset facts, source URLs, measurement limitations, and processing decisions were checked against the cited NASA, USGS, PDS, and Earthdata documentation. AI assistance did not generate planetary observations, feature measurements, similarity rankings, or scientific results. The only production raster used by the engine is the downloaded and provenance-verified USGS Jezero CTX DTM.
